# SWYNEX Technologies — Task 3: Interactive Dashboard

**Objective:** Build an interactive dashboard from the analyzed retail sales dataset.

**Tool:** Power BI Desktop

![Dashboard](dashboard.png)

## KPIs
- Total revenue: 1.64M
- Total transactions: 12,575
- Average transaction value: 130.11

## Features
- Charts: revenue by category, monthly revenue trend, payment method split
- Filters: Category, Location, Payment Method, Transaction Date
- Cross-filtering: clicking any chart updates all KPIs and visuals

## Key Findings
- Payment methods are evenly split: Cash 34.6%, Digital Wallet 32.8%, Credit Card 32.6%
- Online and In-Store sales are almost equal
